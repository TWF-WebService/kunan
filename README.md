# Kunan La Ibérica

Landing migrada desde Elementor a Next.js con Tailwind CSS, estructura modular y recursos locales.

## Comandos útiles

```bash
pnpm dev
pnpm lint
pnpm build
```

## Estructura

- `src/app`: rutas, layout global y estilos base.
- `src/components`: componentes reutilizables y secciones de inicio.
- `src/data`: contenido repetitivo de la landing.
- `public/imagenes/kunan`: assets visuales de la landing.
- `public/documentos`: documentos descargables.
